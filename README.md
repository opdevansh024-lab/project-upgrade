# FORGE Gym App Demo

A self-contained, responsive fitness app prototype built with HTML, CSS, and JavaScript. No build step or dependencies are required.

## Run

Open `index.html` in a browser, or open this folder in Visual Studio Code and use the Live Server extension.

## Features

- Dashboard with daily activity, recovery, workout, and nutrition summaries
- Workout plan and global training style library with search and category filters
- Nutrition tracker with food search, sample macros, meal logging, hydration, and simulated barcode scan
- Swipe-style human trainer discovery plus a 24/7 AI coach preview
- Bottom-right chat widget with sample replies and quick prompts
- Community challenges, worldwide leaderboard preview, gym schedule, and membership card

## Demo limitations

Data is sample data stored in the page session. The AI coach, barcode scan, trainer connections, gym booking, and leaderboard are UI previews; they are not connected to live services or user accounts.
